
# CNN Model on FashionMNIST

## 📌 Overview
This project implements a **Convolutional Neural Network (CNN)** using **PyTorch** to classify images from the **FashionMNIST** dataset. The goal is to demonstrate a complete computer vision workflow including data loading, model design, training, and evaluation.

FashionMNIST consists of grayscale images of clothing items belonging to 10 different categories such as T-shirts, trousers, shoes, and bags.

---

## 🧠 Model Architecture
The CNN architecture used in this project includes:
- Convolutional layers with ReLU activation
- Max Pooling layers for spatial downsampling
- Fully connected (dense) layers for classification
- Softmax output for multi-class prediction

The model is designed to be lightweight while achieving good classification performance.

---

---

## 🗂 Dataset
- **Dataset:** FashionMNIST
- **Classes:** 10
- **Image Size:** 28 × 28 (grayscale)
- **Source:** Provided directly via `torchvision.datasets`
